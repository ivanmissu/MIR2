## 2. 矩阵生成口径（可审计）

矩阵**不做手工统计**，所有事实列从本仓源码机械导出，门禁每 PR 重验：

| 列 | 来源 | 一致性规则 |
|---|---|---|
| `CM`/`SM` 行集与 `code` | `GameOfMir/Common/Grobal2.pas`（GBK 解码，87 条 CM + 215 条 SM，含占位/别名码） | 行键集合 = Delphi 常量集合；`code` 必须同值 |
| `java_constant` | `protocol/ProtocolConstants`（反射枚举字段） | Java 有字段 ⇔ `yes`；Java 集合 ⊆ Delphi 集合（当前两者相等） |
| `wire=gate-game`（CM） | `GameProtocolAdapter.isSupported(int)` 反射真值（按数值逐码调用） | 完全一致，**别名码自动豁免命名歧义**（如 `CM_PASSWORD`=2001 与 `CM_IDPASSWORD` 同码同处理） |
| `wire=gate-login`（CM） | `LegacyGateHandler` 源中 `case/== ProtocolConstants.CM_*` 提取 | 完全一致（LOGIN: 2000/2001/104；SELECT: 100..103） |
| `wire`（SM） | `GameProtocolAdapter`/`LegacyGateHandler` 源中 `ProtocolConstants.SM_*` 出站引用（60 + 13 码） | 完全一致；两入口出站集合必须不相交 |
| `SKILL` 行（177） | `Grobal2.pas` 59 条 `SKILL_*` × {warrior, wizard, taoist} | 全量覆盖；职业归属仅在 GEEM2 Magic.DB 存在 `(MagID, 中文名)` 双匹配时采纳（33 技，其余标注待权威库校准——**1.50 泄露源与 GeeM2 引擎在 34 号后重编号，绝不按编号硬映射**） |
| `MERCHANT`/`GUILD`/`SIEGE` 标签行 | `M2Share.pas` 特殊标签块（`sSL_SENDMSG`..`sHIREGUARDOK`，42 个 `@`/`~@` 标签） | 每个标签必须恰被一个分区认领 |
| `evidence` | 引用的 `*Test` 类名必须真实存在于 `java-server/*/src/test` | 防"幽灵证据" |

**状态五义（矩阵首部 schema 注释有权威定义）：**`implemented`（已复刻+自动化证据）/ `needs-client-check`（本地证据齐、Delphi 字节级 golden 或真实客户端对拍挂账）/ `protocol-only`（有常量无处理）/ `logic-only`（无常量有线处理，预留 0 行）/ `unimplemented`。

## 4. 门禁规则（`G4CapabilityMatrixTest`，10 用例）

1. 格式：9 列 TSV、表头精确、枚举域、(section,key) 唯一、状态↔wire↔java_constant 一致性（如 `implemented` 必须有 wire+evidence，`protocol-only` 必须 `java_constant=yes` 且 wire=none）。
2. 证据实指：evidence 引用的测试类/文档必须真实存在。
3–4. CM/SM 完备性：Delphi 常量集合 = 矩阵行集合（双向）、code 同值、ProtocolConstants 无漂号、无 Java-only 常量。
5–7. 线口真值：CM 两个入口、SM 两个出口分别与实际代码机械一致（§2 表）。**任何新 handler/新出站/新常量不经矩阵直接红灯。**
8. SKILL:59×3 全覆盖（59 是硬断言，Delphi SKILL 集变化先告警）。
9. Market_Def 特殊标签 42 个全量归类（区块移动守卫：标签块移位时门禁先报警而非放行）。
10. GUILD/DEAL 行 code 必须能解析回 CM 行。
